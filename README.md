18. 🧮 The “Maximum Points per Hour” strategy

This is the most important competitive strategy.

Suppose:

Option A

One badge takes 3 hours.

Option B

Three badges take 1 hour each.

If each produces similar point value:

B is better.

So calculate:

Points ÷ Time

Example:

Task	Time	Points	Efficiency
Easy Game	25 min	1	⭐⭐⭐⭐⭐
Medium Game	60 min	1	⭐⭐⭐
Skill Badge	90 min	0.5	⭐
Difficult Challenge	3 hr	1	⭐

Do the highest-efficiency tasks first.
